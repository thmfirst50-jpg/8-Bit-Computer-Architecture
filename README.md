# 8-Bit Computer Architecture

A modular 8-bit computer architecture designed in Logisim Evolution, from arithmetic and registers to instruction sequencing.

## Goal

Connect arithmetic, storage, and control logic into a working computer architecture.

## Design and implementation

Designed an ALU, a 16 × 8-bit register file, program counter, instruction register, memory-address register, decoders, flags, and centralized control unit. Implemented add/subtract operations and microcode sequencing with custom logic gates.

## Project highlights

Integrated binary-coded decimal conversion and 7-segment display logic to turn internal binary results into human-readable numeric output.

## Technologies

- Logisim Evolution
- ALU
- Digital logic

## Repository contents

This repository currently contains the project overview. Source code, design files, test data, and project photos have not been uploaded here. The description documents the project; it is not a runnable software release.
